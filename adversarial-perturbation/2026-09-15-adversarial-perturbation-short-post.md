# What is Adversarial Perturbation?

**Published:** 2026-09-15 · **Author:** Leonardo Jacobi · **Tags:** #AdversarialML #Security #DeepLearning

Adversarial attacks and perturbations are techniques used to exploit vulnerabilities in machine learning models by intentionally manipulating input data. The goal of an adversarial attack is to deceive the model into making incorrect predictions or decisions.

This is particularly relevant for LLM security: prompt injection is essentially an adversarial attack on the model's input layer, where carefully crafted perturbations cause the model to behave outside its intended parameters.
