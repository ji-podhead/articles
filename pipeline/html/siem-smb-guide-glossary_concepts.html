Glossary: Detection & Response Concepts

TERM
MEANING
SIEM
Security Information & Event Management - collect → normalize → detect → correlate → alert → retain.
Attribution
Mapping an event to the workload/identity that caused it (container → session → project) - the layer that makes findings actionable.
eBPF
Linux kernel technology to run sandboxed programs in the kernel - syscall/network observation and enforcement without app instrumentation.
LSM / BPF-LSM
Linux Security Module hook framework (optionally via eBPF) - synchronous enforcement: deny syscalls before they execute.
XDP / XDP_DROP
eXpress Data Path - eBPF programs attached at the NIC; XDP_DROP discards packets at the driver, before the TCP stack.
RCF
Random Cut Forest - unsupervised streaming anomaly-detection algorithm (used by OpenSearch AD and AWS GuardDuty-class services).
FIM
File Integrity Monitoring - watching sensitive files for unauthorized changes.
IaC
Infrastructure as Code - Terraform, CloudFormation, Helm, Kustomize, compose files; scannable by Checkov et al.
SBOM
Software Bill of Materials - a machine-readable inventory of an artifact's components; CycloneDX is the common format.
HITL
Human-in-the-Loop - irreversible actions wait for an operator decision; automation proposes, humans dispose.
Shadow API
An endpoint that exists in traffic but not in documented routes/OpenAPI - the classic gateway-bypass surface.
Data Drift
Model signal decay when live traffic distribution changes vs. training data - triggers retrain, not retuning of rules.
MTTR (p75)
Mean Time To Respond/Remediate, 75th percentile - the runtime KPI containment playbooks can halve.
Blast Radius
How much damage a compromise of one asset can do - the ranking dimension CSPM tools sort findings by.
Warm-start model
A globally trained baseline, fine-tuned per tenant - cheaper than per-tenant training and still isolated.
OCSF / ASFF
Open Cybersecurity Schema Framework / AWS Security Finding Format - schemas that make cross-source correlation possible.
Sigma
Open signature format for detection rules (YAML), consumable by OpenSearch Security Analytics and friends.
Token binding
Binding an API token to a client trait (e.g., TLS fingerprint) so a stolen token fails replay from another machine.
