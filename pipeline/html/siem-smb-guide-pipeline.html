5 · Correlate + attribute

6 · Alert → triage (HITL)

→
7 · Respond + retain
block → isolate → revoke · long-term store
WASN'T
A SIEM is not a scanner. It is a correlate-and-retain engine over EVERY log source - with the alert as the output,
not the feature.
