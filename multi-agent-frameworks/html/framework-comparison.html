Field Comparison

Four frameworks, the deployment questions the pitches go quiet on

RavenAG2 / AutoGenMetaGPTLangGraph
Architecture Centralized orchestrator + EverOS memory. Top-down delegation to Raven-Research / -Code / -Design / -Oncall. Conversable agents in a group chat loop; speaker selection rule-based or LLM-driven. SOP roles (PM, Architect, Engineer) on a publish-subscribe event bus. Cyclic state graph; edges and interrupts explicitly mapped.
Discussion & consensus None organic — orchestrator holds the threads to prevent loops. Creative friction is engineered away. Real debate — free peer discussion, consensus in the loop. Risk: endless moderation-free spirals. Async — agents react to events, no direct chat. Consensus via review gates. Deterministic — consensus loops are graph edges you define.
Inbox bloat & token waste High — interaction is limited by design. EverOS internalizes interactions instead of deleting them. Low — without a smaller model filtering the inbox, agents spam each other. High — no P2P chat clutter; agents react only to published events. Max — built-in checkpointers; state stays small.
Passive SecOps watchdog Not native — no event bus to subscribe to; watchdogs must poll through the orchestrator. Good — SecOps sits in the chat, triggers on keywords, can block the flow. Very good — subscribes to CodeGeneratedEvent, fires SecurityVulnerabilityAlertEvent, freezes the pipeline. Perfect — edge-check after every step; interrupt, stop or roll back the graph.
Shared state Orchestrator-mediated; worktrees left to the operator. Left to the builder: git worktrees + a QA/merge agent are the practical answer. Message-based, less shared-state pressure. State graph with checkpointers; conflicts surface at merge.
Model rivalry Orchestrator caps it — but also caps the honest pushback. Real — Claude vs. Gemini debates burn tokens before code ships. Containers get terminated. Event bus keeps rivals decoupled. Graph edges are neutral — rivalry shows up only where you wire it.

Sources: EverMind-AI/Raven (Apache 2.0, pre-alpha), AG2 / Microsoft Agent Framework, MetaGPT (ICLR 2024), LangGraph (LangChain). Field notes: git worktrees for concurrent agents, gVisor-isolated runtimes (agents terminate raw containers), model rivalry as an identity phenomenon — event-bus and state-graph interrupts keep the watchdogs passive and the tokens alive.
