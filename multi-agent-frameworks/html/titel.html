Beyond the pitch:
which framework survives production?

Raven, AG2, MetaGPT, LangGraph — how they actually handle discussion, consensus, inbox bloat and model rivalry. The questions the launches go quiet on: race conditions on shared state, agents that terminate their teammates, and passive watchdogs that only speak when it matters.
Raven
Centralized harness + EverOS memory. Top-down delegation, no organic peer discussion — by design.
AG2 / AutoGen
Group chat with dynamic speaker selection. Real debate, real token burn.
MetaGPT
SOP roles on a publish-subscribe event bus. Passive listeners without inbox spam.
LangGraph
Cyclic state graph with deterministic edges, interrupts and checkpointers.
