Four tool classes at a glance

What each class gets you - and what it structurally can't give you. None of the four owns the identity chain.
CLASSWHAT YOU GETWHAT YOU DON'T
Gateway / Proxy (OSS)
LiteLLM Proxy
+ unified provider routing
+ user budgets and rate limits
- no process or container identity
- no operating-system enforcement
In-Process Guards (OSS)
LLM Guard · Guardrails AI · NeMo Guardrails
+ native PII masking
+ prompt-injection and toxicity scanning
- runs inside the application process
- not at a centralized network chokepoint
Commercial Platforms
Lakera (Check Point) · Prompt Security · Portkey (Palo Alto)
+ low-latency real-time defense
+ enterprise shadow-AI discovery
- closed-source black box
- external data and trust model
Kernel / Runtime (eBPF)
TigerGate · AgentSight
+ zero-instrumentation intercept
+ operates directly at the TLS / crypto boundary
- sees the host, but lacks the identity chain that provisioned the agent
