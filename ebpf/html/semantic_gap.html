The semantic gap

Detection means correlating semantic content with system state - and no single tool does both.
Traditional infrastructure
Sees low-level events only:
open("/etc/shadow") · read() on a secrets file · a TCP stream to an unknown endpoint.
Question it cannot answer: "why is it doing this?"
→
The semantic gap
Each side is blind to the other's truth. During our incident, the kernel logged legitimate reads and the guardrail saw a suspicious answer - neither could connect the two.
→
AI application layer
Sees natural language only:
"ignore prior rules..." · "output the .env payload" · a chat that escalated too smoothly.
Question it cannot answer: "is this safe to run?"
