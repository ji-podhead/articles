Three learning layers - outcomes flow down, provider truth flows up

Figure 1 · Not one static strategy: a model bandit with decaying memory, a key pool that punishes proportionally to price, and quota truth parsed from headers nobody reads.
Layer 1 · Model bandit - one Beta posterior per platform:model
Evidence goes stale, so it decays: exponential decay with a 2-day half-life, applied lazily on touch - recent behavior dominates.
score = 0.6 × reliability + 0.4 × speed (speed = normalized inverse latency: 1s → 1.0, 10s+ → 0.1). A provider that answers correctly in 30 seconds is not "reliable" for a waiting agent.
Selection: cold-start probe until 5 samples · 10% exploration budget on the least-sampled pair · then greedy on the score, blended 0.7 × bandit + 0.3 × user preference. Honest corner: posterior mean, not a Thompson sample - shipped that way so behavior stays debuggable from logs.
↓ feedback: every proxied call emits a RouteEvent (platform, model, key, latency, tokens, cost, failure) - deterministic 4xx never reach the learners
↑ benches: provider-reported resets, cost-scaled
Layer 2 · Key pool - punishment scaled to price
Per key: EMA reliability + speed posteriors · a model whitelist · cooldown state. The cooldown table is the economy: free 5s · <$0.50 30s · <$3.00 60s · $3.00+ 5 min - and 402 benches the key for 24 hours: retrying an empty paid account on a schedule is poker with your own money.
Benches only extend, never shorten - a provider-informed bench survives a lucky 200. And the ordering principle: paid keys route last; a paid key is never picked while a healthy free key exists.
↓ price-scaled cooldowns applied per key
↑ quota truth: x-ratelimit-* parsed per vendor
Layer 3 · Quota truth - the headers nobody reads
No GET /v1/quota exists - but every authenticated response carries live quota state in x-ratelimit-* headers, plus 429/402 bodies and Retry-After. Parsed per provider, vendor quirks encoded: NVIDIA swaps the header family order, Cerebras namespaces its windows, Anthropic uses its own family.
Confidence model over sources: header 1.0 · error body 0.75 · probe 0.6 - keep the most trustworthy observation per (platform, key, pool, metric), not the newest. Pool inference: Groq meters per account, OpenRouter per :free vs account, Gemini per Cloud project - two keys on one account share one budget. A 200 with remaining: 0 benches the key until the reported reset, with zero failure-stat pollution.
