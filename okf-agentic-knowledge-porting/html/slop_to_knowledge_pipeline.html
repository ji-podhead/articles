The 8-Stage Slop-to-Knowledge Pipeline

from raw research slop to v0.2-compliant OKF - the pipeline that ported ~60 heterogeneous research notes
1. Ingestion & Parsing
logs, exports, IDE chat records
into one uniform buffer
→
2. Scrubbing & Anonymization
regex purges: paths, tokens,
staging IPs
→
3. Token Reduction
strip LLM filler phrases
entirely
→
4. Schema Extraction
deterministic type, topic,
summary → frontmatter
5. Cross-Linking
inject relative links by
shared structure → graph
6. Trust Attestation
lifecycle status + stale_after
+ sources
7. CI Validation
GitHub Actions lint every
frontmatter before merge
8. Zero-Build Serving
static renderer for humans
and agents, concurrently
Stages 2 and 3 are where most of the corpus value comes from - stripping the same filler patterns that would otherwise dominate the embeddings.
Stage 6 is the v0.2 discipline: knowledge has an expiry date.
