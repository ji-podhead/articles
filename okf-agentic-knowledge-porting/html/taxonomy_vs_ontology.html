Taxonomy and Ontology: OKF's Secret Superpower

deterministic structure for instant exclusion - relational depth for traversal that semantic search can't fake
THE TAXONOMY - rigid tree
directory tree + topic / subtopic - rigid, predefined, one home per document
its job: instant, 100%-certain exclusion of irrelevant domains
filter: topic == "general/networking" - deterministic, no relevance guessing
THE ONTOLOGY - relation web
emerges from the Markdown cross-links - any document relates to any other, independent of folders
relation verbs: uses · isolates · depends on
its job: traversal that semantic search can't fake
example edge: "gVisor Container Networking" and "Docker Bridge Isolation" share the tag container-networking
THE BRIDGE: manifest.json
nodes from the frontmatter - edges from taxonomy membership and the cross-links scanned out of the bodies
agent flow for "which security risks does our gVisor networking architecture create for the LLM gateway?": taxonomy filter first, then simply follow the links
a precise answer with no reranking - the relationships were wired by humans and the structuring model, not guessed by cosine similarity
Classic RAG leans on vector similarity alone; OKF gives you both deterministic structure and relational depth - filter by tree, traverse by graph.
