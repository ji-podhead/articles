LLM Mesh
keys · routing · fallback · budgets · analytics · security. Provider keys live once in its vault, never in apps. A mesh, not a proxy: the target is a graph of model pools, nested chains, and fallback edges between providers.

Keys are infrastructure, not config
Vaulted once, rotated in one place; apps never see provider credentials. The .env-with-a-real-key-in-git problem disappears structurally.
Routing + fallback
Free-first with paid keys as the last resort; a chain walk on 429/402/5xx turns a provider's bad minute into a log line.
Budgets + analytics
Per-user and per-team credentials with budget caps, role scoping, and model whitelists; latency, time-to-first-byte, tokens, and cost per app, user, and model.
Security once, at the choke point
Secret-pattern masking, injection guard models (Prompt Guard, Llama Guard), and budget circuit breakers, implemented once in the proxy.
