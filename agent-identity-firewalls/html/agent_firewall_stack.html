The defense: four layers, four questions

Identity answers who, policy answers what, egress answers where, audit answers what happened
LAYER 1 · INGRESS IDENTITY
Who is calling? Strip client claims unconditionally, resolve server-side from the credential, re-stamp from the verified row.
per-agent credentials · RFC 8693 token exchange · SPIFFE SVIDs · use-time injection

layer 1
LAYER 2 · TOOL-CALL POLICY
Is this agent allowed to call this tool? Deterministic allow / escalate / deny, fail-closed, evaluated as code.
OPA Rego · Cedar · OpenAPI schema match · never a model call
WHAT
layer 2
LAYER 3 · EGRESS AND DATA
Where can data go? Default-deny routes: the path to the destination doesn't exist, whatever the container believes. Taint tracking kills read-then-exfiltrate chains; response scanning redacts secrets and PII before they reach the model's context.
14 secret patterns + 5 PII patterns · pass / redact / block
WHERE
layer 3
LAYER 4 · AUDIT AND RECEIPTS
What actually happened? Ground truth recorded outside the model, tamper-evident and replayable. Hugging Face caught the July 2026 breach through its own telemetry, five days before the operator confirmed anything.
HMAC-signed JSONL logs · mediator-signed receipts, verifiable offline · full execution trail for replay
WHEN
layer 4
Miss one layer and the rest carry the weight alone. The nastier failure: a layer that exists but is never consulted.
