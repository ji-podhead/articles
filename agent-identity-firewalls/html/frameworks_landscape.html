Pipelock
github.com/luckyPipewrench/pipelock
Apache 2.0 core, Go
Network mediation
Agent holds secrets but no direct network access; Pipelock holds network access but no agent secrets. Emits mediator-signed action receipts per call, offline-verifiable proof of which agent/thread did what, without a shared credential ever being trusted.
Agent Wall
github.com/agent-wall/agent-wall
MIT
MCP reverse proxy
"Cloudflare for AI agents", wraps an MCP server transparently. Inbound: kill switches, injection detection. Outbound: scans responses for 14 secret + 5 PII patterns before they reach the LLM. YAML policy, allow/deny/prompt per rule.
LlamaFirewall
arxiv.org/abs/2505.03574 (Meta)
Purple Llama, open source
Content safety
PromptGuard 2 + Agent Alignment Checks (chain-of-thought auditor) + CodeShield.
Not authorization, see the Big Tech diagram for why this is a separate layer.
Cedar / Open Policy Agent
cedarpolicy.com/en · openpolicyagent.org
Cedar: AWS. OPA: CNCF-graduated.
Policy-as-code
Deterministic, formally-checkable allow/deny languages. The decision is plain code, an LLM cannot argue its way past a Rego or Cedar policy. A platform can already build its own capability gate on top of either engine directly.
SPIFFE / SPIRE
spiffe.io
CNCF standard
Workload identity
Short-lived X.509 (X.509-SVID) or JWT (JWT-SVID) issued after a local attestor verifies HOW a process launched, distinguishes process A from process B on the same host, even sharing one container image and one IAM role.
Coder
coder.com/docs
verified via own docs
Control-plane isolation
The agent LOOP runs in Coder's control plane, never inside the workspace, so a workspace never holds an LLM-calling credential at all, by construction. No dedicated agent firewall or per-project RBAC described in their own docs, though.
None of these is a substitute for the others, and none of them is "infrastructure"
Every tool above is a layer you bolt onto a network/containers/agents you already have. A platform that provisions the network, the egress firewall, and the containers itself gets that isolation by construction, the tools above add it gets deployed in the first place. The ideas above are worth adopting selectively, see the full research for exactly which two.
