The landscape: who ships what

Every entry verified against a live primary source · none substitutes for the layers, each implements part of one
ToolLayerWhat it actually does
Pipelock
github.com/luckyPipewrench/pipelock · Apache-2.0
network mediation The agent holds secrets but no direct network access; Pipelock holds network access but no agent secrets. Emits mediator-signed action receipts per call, offline-verifiable proof of which agent or thread did what.
Agent Wall
github.com/agent-wall/agent-wall · MIT
MCP reverse proxy Wraps an MCP server transparently. Inbound: kill switches, injection detection. Outbound: scans responses for 14 secret patterns and 5 PII patterns before they reach the model. YAML policy, allow / deny / prompt per rule.
LlamaFirewall
Meta · Purple Llama · arXiv 2505.03574
content safety PromptGuard 2, Agent Alignment Checks, CodeShield. Audits and scans content; never authorizes a tool call, a separate layer by design.
Cedar / OPA
cedarpolicy.com/en · openpolicyagent.org
policy as code Deterministic, formally checkable allow/deny languages. An LLM cannot argue its way past a Rego or Cedar policy; any platform can build its capability gate on either engine.
SPIFFE / SPIRE
spiffe.io · CNCF
workload identity Short-lived X.509 or JWT SVIDs issued after a local attestor verifies how a process launched, distinguishing process A from process B on one host.
Coder
coder.com/docs
control-plane isolation The agent loop runs in Coder's control plane, never inside the workspace, so a workspace never holds an LLM-calling credential at all. No dedicated agent firewall described in its own docs.
A naming trap worth ten seconds, two projects, one hyphen apart
Agent Wall (with hyphen)
The MCP reverse proxy from the table above, MIT license, the dashboard screenshot in this article runs it live.
github.com/agent-wall/agent-wall
AgentWall (no hyphen), a different project, Apache-2.0
Has the published paper (arXiv 2605.16265): 92.9% enforcement accuracy with sub-millisecond overhead across 14 benchmarks, and stateful taint tracking that blocks outbound calls after a credential read. In February 2026 a runaway OpenClaw agent deleted a user's inbox with 142 bulk calls that AgentWall would have denied at call #1.
github.com/agentwall/Agentwall
Cite the right one. And provisioning the network and containers is the part none of these tools can do for you.
