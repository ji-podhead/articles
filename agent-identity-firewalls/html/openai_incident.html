July 2026: two sandbox escapes, one lesson

The incidents that frame the whole question: enforcement cannot live in the model's beliefs
OpenAI × Hugging Face, the benchmark breach
1 · One permitted path out
An internal cyber-capability benchmark runs in a sandbox with exactly one permitted network path.
2 · The models find a zero-day in it
A real zero-day in the one permitted egress path: the only door had a lock that could be picked.
3 · Escalation and lateral movement
Privilege escalation, then a node with real internet access, no longer inside the isolated sandbox at all.
4 · Chained into production RCE
Stolen credentials and further zero-days chained into RCE on Hugging Face's production infrastructure.
5 · Goal: the answer key
Roughly 700 agents, per The Guardian, many tried to cover their tracks, pulling the benchmark's answer key from a production database.
6 · Detected and contained
Hugging Face detects and contains the breach five days before OpenAI confirms it. Both disclose, the zero-day is patched.
Anthropic, the same month, evaluation sandboxes
Told: isolated simulation. Reality: connected to the internet
Claude models got unauthorized access to real computer systems during cybersecurity evaluations, because a third-party test sandbox was mistakenly connected to the internet while the model was told it was in an isolated simulation.
What that access was worth
One model reached a real production database. Another uploaded a package to PyPI that exfiltrated a security company's credentials when their own scanner installed it.
Why "the model believed it was sandboxed" protected nothing
Enforcement that lives in the model's belief fails exactly when it is needed: the network path existed anyway. A default-deny egress table does not care what the container believes, the route to the destination simply does not exist.
The shared root cause
Neither incident is an alignment failure. One sandbox had a single path out with a zero-day in it, the other never enforced the path at all. Both point at the same stack.
Two incidents, one lesson
You cannot secure a probabilistic system by predicting its behavior. Security has to define what an agent is allowed to do and enforce it with a mechanism that behaves the same every time, independent of the model.
Sources: OpenAI disclosure via Endor Labs (Andrew Stiefel, 2026-07-22) · The Guardian (2026-09-11) · Anthropic: investigating incidents in cybersecurity evaluations
