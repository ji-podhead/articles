Context at the edge
Prompt caching ships natively with a session affinity header. Long documents do not belong in KV as a prompt: values up to 25 MiB with eventual consistency (up to 60 seconds), so the honest pattern is KV for hot prompt fragments and Vectorize for retrieval-heavy RAG.
The adapter-as-memory limit holds: a 300 MB rank-32 adapter holds a domain's behavior, not its encyclopedia.
The vLLM counterpart reads the same shape
