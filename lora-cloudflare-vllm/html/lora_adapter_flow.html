Adapters as skills, adapters as memory, adapters as conscience

Three roles, one mechanism: a small weight delta over a frozen base model, swapped per request
SKILL adapter
Deploy flows, firewall operations, agent tools: trained, not prompted. No prompt grows when a skill is added.
MEMORY adapter
Procedural knowledge baked into weights, not a memory file that grows until retrieval drowns. A domain's behavior, not its encyclopedia: retrieval stays external.
GUARDRAIL adapter
The honest persona: a second personality that reviews what the first one did. It flags, it never edits.
↓base + delta, chosen per request
BASE MODEL, frozen weights + low-rank deltas
Training learns two tiny low-rank matrices per touched layer (typically the attention projections q_proj and v_proj); their product is the weight update, scaled by the adapter's alpha. Inference is base plus delta, selected per request. Llama, Mistral, and Gemma bases served by Workers AI or vLLM; QLoRA trains the same deltas on a quantized base.
