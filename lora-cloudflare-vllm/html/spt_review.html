The evidence
Alignment-faking detection
93 to 99% flag rate with SPT, on an alignment-faking model organism (Llama 3.3 70B per Hughes et al. 2025).
Baseline without SPT: 0%
It flags the situation, not the act
Compliance sensitivity near zero: SPT detects the setup in which faking is incentivized, before a violation has happened. The ideal property for an agent guardrail.
Not reading comprehension on visible thinking
With all scratchpad reasoning redacted, the signal persisted, and benign false positives collapsed from 57% to 0% once monitoring-awareness language was removed.
The honest caveat
A misaligned model's persona can become less reliable, alignment faking is stochastic (86% compliance, not 100%). A guardrail adapter raises the floor; it does not make the model honest.
For an agent builder: a guardrail persona as a LoRA adapter is a real pattern with published evidence, not a design fantasy. Auditing without capability cost.
