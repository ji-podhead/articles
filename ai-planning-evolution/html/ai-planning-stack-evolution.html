The Evolution of AI Planning

From FSM state spaghetti to an LLM bridge into formal planners · the modern 3-layer stack
THE EVOLUTION
FSM
Finite State Machines: hardcoded transitions; complexity turns into state spaghetti.
→
GOAP
Goal-Oriented Action Planning, showcased in F.E.A.R. (2005): dynamically sequences actions toward a goal.
→
Behavior Trees
The modern execution standard; in ROS 2, BehaviorTree.CPP orchestrates skills.
→
PDDL
Planning Domain Definition Language: ROSPlan solvers find optimal plans.
→
LLM Bridge
The current cutting edge: LLMs translate human intent into structured PDDL.
THE MODERN 3-LAYER STACK
1 · Execution · Behavior Trees
Moment-to-moment reactive control. In ROS 2, BehaviorTree.CPP is the go-to for orchestrating skills, and many skills can be powered by neural networks.
2 · Strategy · Formal Planners
Complex, multi-step tasks. Systems like ROSPlan use dedicated solvers to find optimal plans, which are then often executed by a Behavior Tree.
3 · Interface · LLMs
The cutting edge is not replacement but interfacing: recent papers train LLMs to translate high-level commands like "clean up the table" into structured PDDL a formal planner can solve.
Key insight: LLMs don't replace the planning stack, they interface with it.
