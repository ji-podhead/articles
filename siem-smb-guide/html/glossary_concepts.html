Glossary: detection and response concepts

The vocabulary the rest of this guide uses deliberately.
SIEM
Security Information and Event Management - collect, normalize, detect, correlate, alert, retain. Not a scanner, not an alert generator.
Attribution
Mapping an event to the workload and identity that caused it (container → session → project) - the layer that turns findings into something you can act on.
eBPF
Linux kernel technology that runs small, verified, sandboxed programs inside the kernel - syscall and network observation plus enforcement, without touching the app.
LSM / BPF-LSM
Linux Security Module hooks (optionally via eBPF) - synchronous enforcement: deny a syscall before it executes.
XDP / XDP_DROP
eXpress Data Path - eBPF programs attached at the NIC; XDP_DROP discards a packet at the driver, before the TCP stack or the app sees it.
RCF
Random Cut Forest - unsupervised streaming anomaly-detection algorithm, built into OpenSearch anomaly detection and GuardDuty-class services.
FIM
File Integrity Monitoring - watching sensitive files for unexpected changes (a system binary that quietly changed).
IaC
Infrastructure as Code - Terraform, CloudFormation, Kubernetes manifests, compose files; statically scannable by Checkov and friends before anything ships.
SBOM
Software Bill of Materials - a machine-readable inventory of an artifact's components (CycloneDX is the common format).
HITL
Human-in-the-Loop - irreversible actions wait for an operator decision; automation proposes, humans dispose.
Shadow API
An endpoint that exists in traffic but not in documented routes or the OpenAPI spec - the classic gateway-bypass surface.
Data drift
Model signal decay when live traffic no longer matches the training distribution - triggers a retrain, not a rule retune.
MTTR (p75)
Mean Time To Respond/Remediate, 75th percentile - the runtime KPI that containment playbooks move.
Blast radius
How much damage a compromise of one asset can do - a ranking dimension posture tools sort findings by.
Warm-start model
A shared global baseline, fine-tuned per tenant - cheaper than per-tenant training and keeps tenants separate.
OCSF / ASFF
Open Cybersecurity Schema Framework / AWS Security Finding Format - the schemas that make cross-source correlation possible (ASFF is OCSF-compatible).
Sigma
Open signature format for detection rules (YAML), consumable by OpenSearch Security Analytics and friends.
Token binding
Binding an API token to a client trait (e.g. a TLS fingerprint) so a stolen token fails replay from another machine.
