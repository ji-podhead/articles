Glossary: platform categories - the CNAPP alphabet

Every serious security tool you evaluate will describe itself using some subset of these letters.
CNAPP
Cloud-Native Application Protection Platform - the umbrella: posture + workload + data + API security bundled by one vendor.
CSPM
Cloud Security Posture Management - finds and ranks cloud misconfigurations: public buckets, over-open security groups.
CIEM
Cloud Infrastructure Entitlement Management - least privilege over identities: finds s3:*-style wildcards, unused keys, over-privileged roles.
CWPP
Cloud Workload Protection Platform - runtime protection of hosts and containers at the syscall and process level.
DSPM
Data Security Posture Management - where sensitive data actually lives, flows, and exits.
API security
Shadow-endpoint discovery, schema enforcement, abuse detection - the layer for endpoints no gateway owns.
AI-SPM
AI Security Posture Management - posture discipline applied to AI workloads: models, prompts, agent identities.
ASPM
Application Security Posture Management - bridges code-level vulnerabilities to cloud-infrastructure exposure.
CTEM
Continuous Threat Exposure Management - the operating loop: enumerate the attack surface, prioritize, validate, remediate.
XDR
Extended Detection and Response - SIEM plus endpoint detection plus correlation under one umbrella.
MDR / managed SOC
Managed Detection and Response - a partner runs 24/7 detection and response for you; the "agentic SOC" products live here.
SOAR
Security Orchestration, Automation and Response - the playbook engine that chains detections into automated actions, with HITL gates on the irreversible ones.
