The AWS-native stack: same job, managed instead of self-hosted

Every self-hosted component of the open-source stack has a directly managed counterpart here - the trade is operational effort for a usage-based bill.
INGEST + EDGE
CloudWatch Logs + Kinesis Firehose
app and infra logs land here by default; subscription filters stream events onward, Firehose batches and delivers to OpenSearch, S3 or Security Lake.
VPC Flow Logs
metadata for every packet: IPs, ports, protocol, bytes, accept/reject - no payload. The raw material for network ML detection.
AWS WAF + Shield
managed L7 rule groups, rate limits and DDoS mitigation at the edge.
↓ detection, audit and scoring
DETECTION + AUDIT - MANAGED
GuardDuty
ML threat detection over flow logs, DNS and CloudTrail, plus runtime monitoring for ECS/EKS. You subscribe, you never train.
Inspector
CVE scanning across EC2 instances, ECR images and Lambda functions.
CloudTrail
signed, immutable log of every API call - who did what, from where, with a 90-day LookupEvents window.
Config
tracks resource state against rules - catches a 0.0.0.0/0 security group before it becomes an incident.
SageMaker
custom ML: Feature Store, training pipelines, Model Monitor for drift.
↓ every finding normalized into ASFF
AWS Security Hub - aggregator and single pane of glass
Pulls findings from GuardDuty, Inspector and your own application via BatchImportFindings, scores the account against CIS, PCI-DSS and other benchmarks, and normalizes every finding into one consistent shape. The AWS equivalent of the Wazuh dashboard - except you don't run it.
↓ query, visualize, retain
OpenSearch Service
managed search and retention layer - the same engine as the OSS stack, minus the operational burden; Security Analytics ships pre-built Sigma rules.
Security Lake
OCSF-normalized long-term security storage, queryable with Athena, for retention that outgrows a hot index.
